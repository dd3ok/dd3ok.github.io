# 채팅 세션과 참고 자료 연결

문제: 브라우저 UUID를 대화 소유권으로 사용하고, 마지막 토큰 이후 1.5초가 지나면 답변 완료로 간주한다. 백엔드의 참고 자료와 실패 신호도 표시하지 못한다.

범위: 기존 채팅 훅·메시지 컴포넌트를 유지하고 서버 발급 세션과 `/ws/chat/events`를 연결한다. 화면 전체 개편이나 새 런타임 의존성은 추가하지 않는다.

1. 서버 세션 발급·보관·만료와 연결 실패 처리.
2. SOURCES/DELTA/DONE/ERROR 처리, 실패한 부분 답변 표시와 명시적 재시도.
3. 참고 자료 제목·검증된 HTTP(S) 링크 표시.
4. 프로토콜 회귀 검사, 타입 검사·빌드·로컬 화면 점검.

완료 기준: DONE 전에는 다음 질문을 보내지 않고, 오류 또는 연결 종료를 성공으로 보이지 않으며, 토큰을 URL이나 화면에 노출하지 않는다. 참고 자료는 문장별 검증된 인용으로 표시하지 않는다.

구현 완료: 서버 세션을 탭 저장소에 보관하고, 이벤트 완료·실패 처리와 참고 자료 표시를 연결했다. UUID 생성 훅과 완료 추정 타이머를 제거했다.

검증: 프로토콜·세션 테스트 5개, 타입·린트·설계 검사와 정적 빌드·스모크 검사를 통과했다. 로컬 모의 서버로 지연 응답 중 전송 잠금, DONE 이후 해제, 부분 실패, 명시적 재시도, 세션 만료 후 재발급, 요청 제한 안내를 브라우저에서 확인했다. 완료된 요청은 재시도 대상으로 남기지 않아 유휴 연결 복구 시 이전 질문이 다시 전송되지 않는다.

배포 조건: 세션 API를 제공하는 백엔드와 함께 반영해야 한다. 원격 push나 운영 배포, 실제 Gemini 품질 평가는 수행하지 않았다.

사용자 확인 반영: 지마켓 종료월을 2025년 1월로 확정해 프런트 표시를 백엔드 이력서와 통일했다. 프로젝트 설명은 확인된 구현 내용만 사용하며, 미확인 선택 이유나 측정 성과를 추가하지 않는다.
