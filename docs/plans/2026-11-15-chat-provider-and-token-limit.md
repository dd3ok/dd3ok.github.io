# 채팅 제공자 전환과 긴 답변 대기

범위: 백엔드의 100milionseek 채팅 전환과 최대 출력 8,192토큰에 맞춰 프로젝트 설명과 응답 대기 시간만 변경한다. Gemini 임베딩과 MongoDB 벡터 검색, 기존 채팅 이벤트 처리는 유지한다.

1. 프로젝트의 채팅 제공자 표기를 실제 연동과 맞춘다.
2. 백엔드 120초 제한 이후 오류를 받을 수 있도록 프런트 대기 시간을 150초로 조정한다.
3. 기존 검증·타입 검사·정적 빌드를 실행하고, 배포 후 실제 채팅과 후속 질문을 확인한다.

완료 기준: 새 API의 답변과 참고 자료가 표시되고, 생략형 후속 질문에서 같은 프로젝트가 유지된다. 응답 완료·오류 전에는 다음 질문 전송을 잠근다. API 키는 프런트에 넣지 않는다.

로컬 검증 완료: 프로토콜·세션 검사 5개, 데이터·설계·린트·타입 검사, 정적 빌드와 스모크 검사를 통과했다.

운영 반영 보류: 사용자 요청에 따라 코드와 PR 준비까지만 진행한다. Gemini 임베딩의 HTTP 402(선불 크레딧 소진)가 해결된 뒤, 별도 배포 요청 시 백엔드·프런트를 배포하고 재색인 및 실제 채팅·후속 질문을 검증한다.
